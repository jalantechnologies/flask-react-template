# Contributing

This page is a front door, not a rulebook. It tells you where the rules live and how to run the
checks locally. The detail stays in the documents linked below so there is one copy of each rule.

## The rules do not change when an AI writes the code

Whether you type the code yourself or an AI assistant produces it, the same standards apply and the
same review happens. Code generated by an assistant is your code once you open the PR: you are
responsible for reading it, understanding it, and defending it in review. "The model wrote it" is
not a review answer.

## Running tests and lint locally

Run these before you push. CI runs the same commands.

```bash
npm run test           # backend pytest + frontend vitest
npm run test:frontend  # frontend suite only
npm run lint           # mypy, pylint, eslint, remark
npm run fmt            # autoflake, isort, black, prettier
```

[Testing](testing.md) explains the suite layout, the Docker option, and the coverage floors CI
enforces. [Code Formatting](code-formatting.md) explains the formatters and the pre-commit hook.

## Opening a pull request

Titles use the Conventional Commit format and drive auto-labeling and semver. Descriptions are
written for a reader with no background on the change.

The full convention is in [.claude/skills/pr-conventions/SKILL.md](../.claude/skills/pr-conventions/SKILL.md).
After you open or push to a PR, work it to green with
[.claude/skills/pr-review-loop/SKILL.md](../.claude/skills/pr-review-loop/SKILL.md).

Fill in the [pull request template](../.github/pull_request_template.md) checklist honestly. An
unticked box with a reason is more useful than a ticked one that is not true.

## One source of truth

The files under `.claude/skills/` are the canonical detailed source for the workflows they describe.
This page and the AI assistant instructions point back at them rather than restating them, so a rule
is changed in exactly one place. If you find a rule written out twice, the copy in `.claude/skills/`
wins and the other one should become a link.
